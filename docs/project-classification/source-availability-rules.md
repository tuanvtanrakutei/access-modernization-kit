# Source Availability Rules

| Value | Contract |
|---|---|
| `full` | Editable project/database source is available through an authorized method |
| `compiled_only` | Only compiled frontend evidence exists; VBA analysis remains limited |
| `exported_only` | A validated export exists without the original project file |
| `mixed` | Availability is declared per artifact |

Canonical rules: `plugins/ak/profiles/source-availability.yaml`.
