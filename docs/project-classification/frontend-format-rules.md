# Frontend Format Rules

MDB and ACCDB require inspectable Access object inventories. ACCDB additionally requires data-macro coverage.
ADP requires SQL Server schema and programmable-object evidence; ADP alone cannot make Phase 1 or Phase 3 ready.
MDE and ACCDE are compiled-only constraints and cannot support a complete VBA reconstruction claim.
`exported` requires a validated producer/export manifest.

Canonical rules: `plugins/ak/profiles/frontend.yaml`.
